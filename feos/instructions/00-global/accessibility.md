# L1 Global — Accessibility

- Target WCAG 2.2 AA for all user interfaces.
- Semantic HTML / native controls first; ARIA only to fill gaps.
- Keyboard operable, visible focus, contrast ≥ 4.5:1 (text), text alternatives, captions for media.
- Automated checks (e.g. axe) in CI for UI changes plus a manual keyboard pass recorded in task evidence.
